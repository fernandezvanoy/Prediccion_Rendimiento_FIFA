# Predicción de Evolución del Rendimiento en FIFA

Predice si el overall de un jugador de FIFA subirá, bajará o se 
mantendrá estable en la siguiente versión del juego, usando 
LightGBM y reportes de scouting generados con LLM (Groq).

FIFA 15–20 Complete Player Dataset  
https://www.kaggle.com/datasets/stefanoleone992/fifa-20-complete-player-dataset


## Instalación
pip install -r requirements.txt

## Ejecución
1. Abrir `notebooks/prediccionFIFA.ipynb` en Google Colab
2. Ejecutar todas las celdas en orden
3. Antes de llegar a la sección de 'Streamlit', ve al menú lateral en la parte izquierda y presiona el botón de 'Archivos'.
4. Presiona el botón 'Subir al almacenamiento de sesión' y agrega el archivo `app.py` que esta dentro de la carpeta `app/`

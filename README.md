# Predicción de Evolución del Rendimiento en FIFA

Predice si el overall de un jugador de FIFA subirá, bajará o se 
mantendrá estable en la siguiente versión del juego, usando 
LightGBM y reportes de scouting generados con LLM (Groq).

## Dataset
FIFA 15–20 Complete Player Dataset  
https://www.kaggle.com/datasets/stefanoleone992/fifa-20-complete-player-dataset

pip install -r requirements.txt
